#Supply Chain Performance Analysis

#Project Overview

This project analyzes 180,519 supply chain transactions to identify delivery bottlenecks, product profitability issues, and regional sales performance.

Tools Used
Python (Pandas)
Jupyter Notebook
Power BI
GitHub


1) Which product categories generate the most revenue?
2) What percentage of deliveries are late?
3) Which shipping modes perform best?
4) Which products generate the highest and lowest profits?
5) Which regions generate the most sales?
   
#Key Findings

54.8% of deliveries were late.
Fishing generated the highest category revenue.
First Class shipping showed the highest late-delivery risk.
Several products generated negative overall profit.
Revenue is concentrated in a small number of cities.

#Recommendations

Investigate First Class delivery processes.
Reassess pricing strategy for loss-making products.
Prioritize inventory planning for top-performing categories.
